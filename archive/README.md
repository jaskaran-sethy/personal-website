# Archive

Code and images from the 2023 version of the site, plus originals of images that were replaced by
compressed copies (e.g. `mountainMe.jpg` → `public/mountainMe-*.webp`). Nothing here is imported or
served: Next.js only builds what `pages/` imports and only deploys `public/`, so this folder stays out
of the site. Files keep their old relative paths, so moving one back to where it was restores it.
